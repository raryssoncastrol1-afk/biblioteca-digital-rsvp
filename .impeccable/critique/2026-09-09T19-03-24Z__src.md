## Veredicto de Especificidade

Parcialmente específico — o leitor RSVP foveal é autoral (vermelo focal, ORP, crosshair), mas a biblioteca é um dashboard SaaS indigo genérico e intercambiável. Dois sistemas de acento discordam (indigo library vs vermelho reader).

## O que está funcionando

1. Aceleradores do leitor (keyboard map completo, swipe/double-tap parity, HelpModal)
2. Estágio foveal ORP (dwell-time calibrado, fontSize clampado)
3. Ações destrutivas protegidas (delete dialog nomeia livro/autor, autoFocus no safe action)

## Problemas Prioritários

**[P1] Empty state conflado** — LibraryView.jsx:261-274 renderiza "Nenhum livro → importe arquivos" mesmo para busca sem resultados. Comando: clarify

**[P1] Ações icon-only, hover-hidden, sem labels** — BookCard.jsx:55-78, BookTable.jsx:55-85; sem focus-visible nem aria-label. Comando: adapt

**[P1] Modais sem dialog semantics, focus trapping, empilháveis** — nenhum role="dialog"/aria-modal; C+S empilha dois modais (App.jsx:295-312). Comando: audit

**[P1] Fim-de-livro anti-clímax** — RSVPReader.jsx:102-106 congela sem feedback; Peaks-End violado. Comando: delight

**[P2] Hierarquia invertida** — stats text-2xl sobrepõem títulos; WPM médio enganoso; indigo vs vermelho quebra identidade. Comando: distill

**[P2] 4 padrões AI-slop do detector** — gradient-text, paleta indigo genérica, animate-bounce, border-accent-on-rounded (este último false positive). Classes Tailwind v4 em CDN v3 (no-ops), config brand-* orfanã, plugin animation não carregado. Comando: polish
